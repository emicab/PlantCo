## Como ejecutar el proyecto paso a paso
1. Clonar el repositorio:
git clone https://github.com/emicab/PlantCo.git

2. Instalar dependencias o abrir el proyecto:
npm install

3. Ejecutar el proyecto:
Abrir index.html con Live Server o ejecutar `npm run dev`
